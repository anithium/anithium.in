# ANITHIUM

Company website.

## Frontend

The Next.js application lives in the `frontend/` directory.

```bash
cd frontend
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run start
```

## Project structure

```
frontend/
  public/
    images/
  src/
    app/
  package.json
  next.config.ts
  tsconfig.json
```
